# 书法项目 · 领域词汇表（i18n.zh）

> 用途：统一项目内中英术语口径。来源标注：🧑=Owner 一手表述 / 🌐=研究资料二手提炼 / ⚙️=本工具实现约定。

| 中文 | English | 备注 | 来源 |
|---|---|---|---|
| 转录 / 转写 | transcription / transcribe | 音频→文字；项目内统一说「转录」 | 🧑 |
| 语音识别 | ASR (Automatic Speech Recognition) | 转录的技术名称 | 🌐 |
| 字错误率 | CER (Character Error Rate) | 中文评测主指标，越低越好 | 🌐 |
| 词错误率 | WER (Word Error Rate) | 英文评测主指标 | 🌐 |
| 实时率 | RTF (Real-Time Factor) | 处理 1 秒音频耗的秒数，越小越快 | 🌐 |
| 逆文本规范化 | ITN (Inverse Text Normalization) | 「九点」→「9点」等数字/日期规范化；SenseVoice 由 use_itn 开启 | 🌐 |
| 热词 / 上下文词表 | context / hotwords | `--context "楷书 中锋 提按…"`，提升领域术语命中率 | 🌐 |
| 说话人分离 | diarization | 区分「谁在说」；mlx CLI `--diarize` | 🌐 |
| 时间戳 | timestamps | 词级时间标注；SRT/VTT 字幕依赖它 | 🌐 |
| 量化 | quantization (4-bit / 8-bit) | 缩小模型体积；4-bit 略损精度，默认 small 档用 4-bit | 🌐 |
| 离线 / 批量转录 | offline / batch transcription | 本项目唯一模式；流式因上游缺陷暂不启用 | ⚙️ |
| 流式（实时）转录 | streaming transcription | Qwen3-ASR 伪流式有重复缺陷（issue #129） | 🌐 |
| 中英混合 | code-switching | 中文语句夹英文术语；Qwen3-ASR 训练最系统 | 🌐 |
| 音频规范化 | audio normalization | 统一转 16kHz 单声道 s16 WAV（ffmpeg；WAV 直通） | ⚙️ |
| 引擎 | engine | mlx / cuda / cpu 三档，平台探测自动选，`--engine` 强制 | ⚙️ |
| 书法热词表 | calligraphy context words | 楷书 行书 草书 隶书 篆书 中锋 侧锋 提按 转折 飞白 藏锋 露锋 | 🧑 |
